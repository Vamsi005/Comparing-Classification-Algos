# Project‑Final Year

This repository contains the code and data for the final‑year project, including sentiment analysis models for IMDB and Twitter datasets.

## Directory structure
```
Project-Final Year/
├─ app-fin.py                 # Main application script
├─ imdb‑training.ipynb        # Notebook for training IMDB models
├─ twitter‑training.ipynb     # Notebook for training Twitter models
├─ data/                      # Raw datasets (CSV)
├─ imdb‑sentiment‑analysis/   # IMDB specific scripts/models
├─ twitter‑sentiment‑analysis/ # Twitter specific scripts/models
└─ README.md                  # This file
```

## Quick start
1. Install required packages (see `requirements.txt` if present).
2. Run `python app-fin.py` to launch the demo.
3. Explore the notebooks for training/evaluation.
